# 基于 OpenCV 的灯带识别与目标位移解算

## 1. 项目简介

本项目用于实现机器人搭载 RGB 相机后的目标灯带识别，并根据灯带在图像中的几何信息，进一步解算目标相对于相机的空间位置。

当前项目主要基于：

* Python
* OpenCV
* Intel RealSense
* NumPy

当前已经实现：

* RealSense RGB 相机初始化
* 相机内参获取
* 实时 RGB 图像读取
* HSV 颜色分割
* 形态学处理
* 灯带轮廓提取
* 灯带几何筛选
* 两条灯带目标识别
* 目标中心计算
* 灯带间距计算
* 灯带方向计算
* 实时结果可视化

后续将在此基础上完成目标空间位置解算。

## 4. 各模块说明

### `main.py`

程序入口。

负责：

1. 获取相机内参
2. 创建相机对象
3. 循环获取实时图像
4. 调用图像处理模块
5. 显示处理结果
6. 退出时关闭相机

主程序本身不负责具体的图像处理算法。

---

### `camera_intrinsics.py`

负责获取 RealSense RGB 相机的内参。

主要参数：

```text
fx —— x 方向焦距
fy —— y 方向焦距
cx —— 主点 x 坐标
cy —— 主点 y 坐标
```

同时获取相机畸变模型和畸变参数。

主要接口：

```python
get_intrinsics()
```

---

### `camera.py`

对 RealSense 相机进行简单封装。

主要功能：

* 初始化 RGB 视频流
* 获取实时图像
* 关闭相机

主要接口：

```python
camera = Camera()

frame = camera.get_frame()

camera.stop()
```

当前 RGB 图像配置：

```text
分辨率：640 × 480
帧率：30 FPS
格式：BGR8
```

---

### `image_process.py`

负责当前已经完成的视觉处理流程。

处理步骤：

```text
BGR
 ↓
HSV
 ↓
颜色阈值
 ↓
形态学闭运算
 ↓
轮廓提取
 ↓
最小外接矩形
 ↓
长宽比筛选
 ↓
灯带候选
 ↓
目标几何信息
```

当前使用的主要参数：

```text
HSV Lower = (0, 100, 100)
HSV Upper = (20, 255, 255)

形态学 Kernel = (3, 42)

最小长宽比 = 10
```

主要接口：

```python
process_image(frame)
```

返回：

```python
result
mask
target_geometry
```

其中 `target_geometry` 当前包含：

```text
target center
center distance
target angle
led1
led2
```

---

### `pose_solver.py`

用于后续实现目标空间位置解算。

当前暂未实现。

计划根据：

* 图像中的目标几何信息
* 目标实际尺寸
* 相机内参
* 相机畸变参数

计算目标相对于相机的空间位置。

## 5. 环境依赖

建议使用 Python 3 环境。

安装主要依赖：

```bash
pip install opencv-python numpy pyrealsense2
```

同时需要正确安装 Intel RealSense SDK。

## 6. 运行

确认 RealSense 相机连接后，在工程根目录运行：

```bash
python main.py
```

程序运行后会显示两个窗口：

```text
RealSense RGB
Mask
```

其中：

* `RealSense RGB`：实时识别结果
* `Mask`：颜色阈值和形态学处理后的二值图像

按：

```text
q
```

退出程序。

## 7. 当前识别结果

当前程序能够在实时 RGB 图像中：

* 检测灯带候选区域
* 使用长宽比筛选灯带
* 获取灯带中心
* 获取灯带四个角点
* 获取灯带方向
* 在检测到至少两条灯带时计算目标中心
* 计算两条灯带中心之间的像素距离
* 显示目标中心、距离和方向

示意：

```text
        LED 1              LED 2
          │                  │
          │                  │
          │                  │
          ●────── TARGET ────●
```

## 9. 注意事项

当前视觉识别参数针对现有测试环境进行了调整。

其中：

```text
HSV 阈值
形态学 Kernel
长宽比阈值
```

均可能受到以下因素影响：

* 环境光照
* 灯带颜色
* 相机曝光
* 灯带与相机之间的距离
* 背景颜色和纹理

如果更换实际测试环境，需要重新验证这些参数。
